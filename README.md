
# KLYRO Frontend (React + Vite)

**Do not change the approved design without explicit request.**

## Scripts
- `npm install`
- `npm run dev` (local)
- `npm run build` (production bundle)
- `npm run preview` (serve built files)

## Design rules (frozen)
- White background
- Smoke hourglass symbol
- "KLYRO" black-glass text (top-right)
- Centered "Welcome" in header
- Sidebar on the left
- Holographic dark‑green/cyan accents
- Role-based visibility (Participant, Admin, SuperAdmin)

## Environment
No env vars required for local UI preview. Backend URL is assumed `http://localhost:4000` (configure later).
